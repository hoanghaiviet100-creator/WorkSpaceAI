\chapter{Quá trình phát triển}

\section{Phân công thành viên}

{\itshape
Liệt kê rõ ràng từng thành viên trong nhóm, vai trò (ví dụ: Backend Developer, Frontend Developer, UI/UX Designer, Tester) và các module hoặc chức năng chính mà mỗi thành viên chịu trách nhiệm phát triển cho hệ thống.
}

\section{Kết quả đã đạt được}

{\itshape
Trình bày cụ thể các chức năng hoặc module của hệ thống đã hoàn thành (đã code xong, đã chạy thử) tính đến thời điểm hiện tại, so sánh với các mục tiêu đã đề ra ở Chương 1.
}

\section{Kế hoạch giai đoạn tiếp theo}

{\itshape
Trình bày một lộ trình (roadmap) hoặc thời gian biểu (timeline) chi tiết cho các công việc còn lại, bao gồm các mốc quan trọng (milestones) cho việc hoàn thiện các tính năng, kiểm thử (testing), và chuẩn bị cho báo cáo cuối kỳ; có thể sửu dụng Sơ đồ Gantt (Gantt Chart) để trực quan hóa kế hoạch này.
}

\section{Khó khăn và rủi ro}

{\itshape
Liệt kê các vấn đề kỹ thuật (ví dụ: "Khó khăn khi tích hợp API của bên thứ ba", "Thuật toán gợi ý hoạt động chưa chính xác") hoặc phi kỹ thuật (ví dụ: "Quản lý thời gian", "Thiếu dữ liệu du lịch thực tế") mà nhóm đã gặp phải hoặc dự đoán sẽ gặp, cùng với các giải pháp đã hoặc dự kiến sẽ áp dụng.
}
