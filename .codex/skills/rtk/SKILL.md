# RTK

Use the workspace installation at `H:/WorkSpaceAI/.codex/tools/rtk/rtk.exe`. In PowerShell, invoke it with the call operator, for example:

```powershell
& 'H:/WorkSpaceAI/.codex/tools/rtk/rtk.exe' git status --short
```

Use RTK for supported commands when a compact result is sufficient. Run the original command when exact output is needed or the filtered result omits relevant detail. Follow the repository's verification instructions.

See [RTK Quick Start](references/quick-start.md) for command examples and [the official RTK repository](https://github.com/rtk-ai/rtk) for current documentation.
